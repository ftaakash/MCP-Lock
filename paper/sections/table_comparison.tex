\section{Performance Comparison with Existing Methods}
\label{sec:compare}
Table~\ref{tab:compare} puts MCP-Lock next to the baseline hook in both readings and next to two steps that need no gate,
all on the corpora of Section~\ref{sec:eval}. On npm real attacks, the baseline hook plus \code{-{}-ignore-scripts} detects about as
many cases as \G{} (\SCIgnP{} vs.\ \GNpmP), so most of \G's gain on real attacks is available more cheaply. The hook
detects none of the synthetic rug pulls (\RSSC) and \G{} detects all of them (\RSG). Exact version pinning
prevents every attack on an existing package (\PinRMP{} of R-M) and, by construction, every rug pull, but only by
holding back all \NB{} benign upgrades until the user edits the configuration; \G{} lets an upgrade run unattended when
nothing it checks has changed. We did not replay \code{-{}-ignore-scripts} on the synthetic rug pulls.
